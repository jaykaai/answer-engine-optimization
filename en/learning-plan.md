# AEO（Answer Engine Optimization）系统学习计划

## 概述

AEO（答案引擎优化）是 SEO 的自然延伸，目标是让你的内容被 AI 答案引擎（如 ChatGPT、Perplexity、Google AI Overviews、Bing Copilot 等）直接引用为答案来源。

**核心思维转变：** 从"关键词排名"转向"问题覆盖"。AI 不是在匹配关键词，而是在理解用户意图后，从它认为权威、结构清晰、可直接提取的内容中生成答案。

- `@id` 用于实体去重和引用

### 5.2 AEO 内容优化清单

实验时逐项检查：

- [ ] 每个 H2 标题写成一个问题
- [ ] 紧随标题用一句话直接回答（40-60 字）
- [ ] 展开解释，提供细节和案例
- [ ] 使用列表、步骤等结构化格式
- [ ] 添加 FAQPage 或 QAPage Schema（JSON-LD 格式）
- [ ] 添加 Article Schema（JSON-LD 格式）
- [ ] 关联实体（`sameAs` 指向 Wikipedia、Wikidata 等权威来源）
- [ ] 内容同时在多平台分发（YouTube、Reddit/知乎、行业论坛）
- [ ] 使用 Google Rich Results Test 验证 Schema
- [ ] 提交至 Google Search Console 请求索引

### 5.4 实验步骤

1. 选 5-10 个你所在领域的用户真实问题（用 5.1 的工具找）
2. 为每个问题写一篇按 AEO 原则优化过的内容（参考 5.2 清单）
3. 发布后 2-4 周，在 Perplexity、ChatGPT（联网模式）、Google 上测试这些问题
4. 记录哪些被引用、哪些没有，分析原因，迭代
5. 循环：优化 → 发布 → 测试 → 记录 → 迭代

## 常见误区

很多人以为 AEO 就是"给 AI 写内容"。不是的。AI 引用的是你为**人**写的内容，只是结构需要让 AI 容易解析。如果你为了讨好 AI 而牺牲人的阅读体验，AI 反而不会引用你——因为 AI 引擎的终极目标是给用户好的答案，它判断"好答案"的标准最终还是会回归到人的反馈上。
