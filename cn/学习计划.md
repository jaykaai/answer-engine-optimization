# 中国 AEO（答案引擎优化）系统学习计划

> 面向中国大陆市场。覆盖百度搜索生态 + 中国 AI 答案引擎（百度AI搜、秘塔、Kimi、豆包、通义千问等）。
> 对应国外版本见 [en/learning-plan.md](../en/learning-plan.md)

---

## 概述

中国 AEO 的目标：让你的内容被中国的 AI 答案引擎直接引用为答案来源。

**核心思维转变：** 在中国市场，AEO 不是脱离 SEO 的新东西，而是**百度SEO 的自然延伸**。因为中国 AI 搜索的底层数据源绝大部分来自百度索引——百度AI搜、秘塔、Kimi、通义千问的联网搜索，都高度依赖百度已收录的页面。**在中国做 AEO，首先得做好百度SEO。**

### 1.2 百度搜索核心概念

| 概念 | 说明 |
|------|------|
| **Baiduspider** | 百度爬虫，与 Googlebot 行为不同。百度对 JS 的渲染能力有限，**依赖原始 HTML** |
| **百度索引量** | 你的页面被百度收录的数量，不等于你提交的数量 |
| **百度权重** | 第三方工具（爱站、站长之家）的估算指标，百度官方不承认但业界广泛使用 |
| **百度 EEAT** | 百度的"搜索质量评估标准"：权威性、专业性、可信度、用户体验。与 Google EEAT 类似但侧重点不同 |
| **原创保护** | 百度对原创内容的识别和倾斜。百度站长平台可提交原创声明 |
| **熊掌号** | 百度过去的生态项目，已下线但遗产仍在影响搜索排名 |
| **移动适配** | 百度对移动端友好度要求极高，MIP 已淘汰但移动优先原则不变 |

### 3.2 中国 AEO 核心策略

1. **百度索引是第一道门槛** — 页面没被百度收录，任何中国 AI 引擎都不会引用你
2. **知乎是中国 AEO 的超级节点** — 几乎所有中国 AI 引擎都优先引用知乎内容
3. **百度百科是实体建设的基础** — 百度AI搜和秘塔对百科的引用率极高
4. **百度系内容有先天优势** — 百家号、百度知道在百度AI搜中引用率更高
5. **自建站需要ICP备案** — 否则国内服务器不可用，香港服务器在百度收录上会略有延迟

## 常见误区（中国版）

1. **"我做了百度SEO就是做了AEO"** — 百度SEO是AEO的前提，但不是全部。做了百度SEO只是内容能被索引，不等于会被AI搜索引用。还需要段落化优化、QAPage结构化数据、多平台权威建设。

2. **"内容放在公众号上就够了"** — 微信公众号是封闭生态，百度不索引，中国AI搜索也搜不到。公众号内容对AEO完全无效。

3. **"百度不收录就是不收录，没办法"** — 百度收录问题是可解的：检查robots.txt是否误拦Baiduspider、是否有JS渲染问题、内容是否原创、是否通过百度搜索资源平台提交。

4. **"AI搜索会引用所有百度收录的内容"** — 不会。AI搜索有引用偏好。知乎、百度百科、CSDN等权威平台的引用率远高于普通自建站。即使同样被百度收录，权威度高的来源被引用的概率大得多。

5. **"Schema没用，百度不认"** — 百度确实对部分Schema类型支持有限，但它支持QAPage、Article、BreadcrumbList、Organization等关键类型。结构化数据不是加分项，而是AEO的基础设施。
