## 第一卷：为什么做 GEO

### 第一章 时代的转折点

**核心洞察：** 用户获取信息的方式正在从"搜索→点击网页"转向"提问→直接获得答案"。当人们不再逐个浏览网页，而是直接向 AI 提问时，你的内容必须被 AI 引用才能被看见。

**关键数据：** AI 生成回答中，被引用的内容集中在少数高质量来源。如果你的内容不在这些来源中，AI 时代你就隐形了。

### 第二章 我的故事

**背景：**
- 计算机专业毕业，体制内工作（不做技术）
- 对 AI 智能体应用感兴趣
- 目标：成为 GEO 专家 → 帮商户让 AI 推荐他们的产品

**业务模式（自举式）：**
- 学 GEO → 写 GEO 内容 → 让 AI 引用你的内容
- "AI 引用你" = 你懂 GEO 的铁证
- 客户搜 GEO 时看到你被引用 → 自然找上门
- 帮商户让 AI 引擎引用他们的商品信息（GEO 代运营/咨询）

### 第三章 术语之战：GEO 还是 AEO？

**关键发现（实测验证，非理论推断）：**

| 术语 | 中文搜索情况 | 结论 |
|------|-------------|------|
| 答案引擎优化（AEO） | 秘塔只能引用英文站翻译，无中文内容 | ❌ 不适用 |
| 生成式引擎优化（GEO） | 大量中文结果（louishe.com、ithome、tech.china 等） | ✅ 正确术语 |

**结论：** 在中国，写内容、做 SEO 都用 **GEO（生成式引擎优化）**，不是 AEO。

### 第五章 推翻"知乎超级节点"假设

**原有假设：** 知乎是中国 AI 搜索的超级节点，几乎所有引擎都优先引用知乎。

**实测验证（用户亲自在秘塔/豆包/千问搜"GEO"）：** 0 个引用来自知乎。被引用的是：
- 个人博客（louishe.com）
- 科技媒体（ithome、tech.china、ifeng）
- 开发者平台（aliyun）
- 学术平台（zenodo）

**结论：** 技术性新话题优先引用**原创文章**（自建站/科技媒体），非问答平台。平台选择必须用实测验证，不能沿用国外经验推断中国生态。

### 第六章 规格书的诞生

从分析被引用页面（louishe.com 的 GEO 文章）的 HTML 结构，量出 4 条核心规则：

| # | 规则 | 被引用段落实例 |
|---|------|---------------|
| 1 | H2 写成完整问句 | "什么是生成引擎优化（GEO）？" |
| 2 | 紧跟标题第一句即完整答案 | 标题下直接给出定义 |
| 3 | 直答句自带主语全称（自足段落） | "生成引擎优化 (GEO) 是一种..." 而非"它是一种..." |
| 4 | 先一句结论，后展开细节 | 定义句后紧跟展开说明 |

**核心原理：** AI 引擎在生成回答时，从原文中摘取段落（chunk）作为引用。这些 chunk 脱离标题后必须依然独立成文，所以直答句必须自带主语全称。

## 第三卷：建站 — 大道至简

### 第七章 部署方案决策

**需求：** 需要一个能被 AI 引擎索引和引用的网站。

**方案对比：**

| 方案 | 费用 | 备案 | 维护 | 选型 |
|------|------|------|------|------|
| GitHub Pages + 自定义域名 | 免费 | 不需要 | 零维护 | ✅ 选定 |
| 国内服务器 | 月付 | 需要 ICP 备案 | 有维护 | ❌ 暂不 |
| 香港服务器 | 月付 | 不需要 | 有维护 | ❌ 暂不 |

**域名：** 阿里云注册 `jiyou.site`（实名域名，年费约 30 元）

### 第八章 建站原则

**核心理念：** 目标是让 LLM 读 HTML，不是给人看精美的 UI。

- **纯静态 HTML 完全足够** — 不引入框架，不堆 JavaScript
- **HTML 体积应在 KB 级** — 对照 Ahrefs 850KB 的反面标本
- **robots.txt 全部放行** — 没有任何理由屏蔽 AI 爬虫
- **JSON-LD 手写** — Article + Person + Organization + sameAs

### 第九章 DNS 配置与 HTTPS 的血泪史

**大坑记录：**

1. **域名解析配置：** 需要同时配置 @（apex）和 www 两条记录
   - `@` 用 A 记录指向 GitHub Pages IP
   - `www` 用 CNAME 指向 `jaykaai.github.io`

2. **CNAME 冲突问题：** 如果 `www` 已经有 A 记录，添加 CNAME 会冲突。需要先删除 A 记录再添加 CNAME。

3. **HTTPS 证书等待：** GitHub 使用 Let's Encrypt 自动签发证书，配置域名后需要 **24-48 小时**生效。耐心等待，不是配置问题。

4. **自定义域名变更：** 中途从 `jiyou.site` 改为 `www.jiyou.site`，所有文件中的硬编码域名（canonical、JSON-LD 中的 url、sitemap、robots.txt 中的 Sitemap 地址）都需要同步更新，否则 canonical 和实际域名不一致会影响 SEO。

### 第十章 网站文件清单

| 文件 | 说明 | 技术要点 |
|------|------|---------|
| `index.html` | 首页，文章列表 | JSON-LD: WebSite + Person |
| `geo-shi-shen-me.html` | 第一篇 GEO 文章 | JSON-LD: Article + Person，QAPage 风格 H2 |

## 第四卷：内容创作 — 让 AI 引用你

### 第十一章 第一篇 GEO 文章

**文章标题：** 《什么是生成式引擎优化（GEO）？和传统SEO有什么区别？》

**写作要点：**
- 每个 H2 写成完整中文问句
- 紧随标题第一句直接给出答案（自足段落）
- 使用完整的句子和明确的定义
- 多平台实体建设（知乎 sameAs）

### 第十二章 JSON-LD 结构化数据

**手写 JSON-LD 的三个实体：**

1. **Article** — 文章元数据（标题、描述、作者、发布时间、语言）
2. **Person** — 作者实体（姓名、URL、描述、sameAs 指向知乎）
3. **Organization** — 发布者实体

**关键字段：**
```json
{
  "sameAs": ["https://www.zhihu.com/people/jaykaai"],
  "knowsAbout": ["生成式引擎优化", "AI搜索优化", "AI智能体", "GEO", "AEO"]
}
```

### 第十三章 robots.txt 策略

**原则：** GEO 的核心目标就是被 AI 引用，没有任何理由屏蔽任何爬虫。

```txt
User-agent: *
Allow: /

User-agent: GPTBot
Allow: /

User-agent: OAI-SearchBot
Allow: /
```

**教训：** 国外如 Moz 只屏蔽 GPTBot 训练爬虫但放行搜索爬虫，因为训练爬虫和搜索爬虫应该分开决策。但我们的站点无版权顾虑，所以全部放行。

## 第五卷：提交与等待

### 第十四章 百度搜索资源平台

**操作步骤：**
1. 注册/登录 [百度搜索资源平台](https://ziyuan.baidu.com)
2. 添加站点（输入域名 `www.jiyou.site`）
3. 验证网站所有权（选择文件验证，将验证文件上传到站点根目录）
4. 提交 sitemap（**新站点有配额限制**，当日提交上限为 0 条是正常现象）

**遇到的坑：**
- 新站点不会立即开放 sitemap 提交权限，百度需要先确认站点真实有效
- 替代方案：手动提交单个 URL（每天有少量配额）

### 第十五章 等待收录

**关键认知：** 新站点从上线到被 AI 引擎引用需要时间。

- 百度爬虫自然抓取周期：几天到几周
- AI 引擎发现新站点：滞后于搜索引擎
- 当前状态：1 篇文章，内容太少，被发现的概率低

**结论：** 最有效的方法不是干等，而是**继续写更多文章**，增加内容厚度。

## 第六卷：实战心得

### 第十六章 核心方法论

**GEO 的核心公式：**

```
GEO 效果 = 内容质量 × 页面数量 × 权威度 × 时间
```

- **内容质量：** 自足段落、结构化数据、清晰的语义结构
- **页面数量：** 文章越多，被发现的概率越大
- **权威度：** 多平台实体建设（自建站 + 知乎 + 未来百度百科）
- **时间：** 耐心，AI 引擎的索引和引用不会一夜之间发生

### 第十七章 常见误区

1. **"GEO 就是新 SEO"** — 不是。SEO 优化排名，GEO 优化被引用。排名靠前的内容不一定被引用，被引用的内容不一定排名靠前。

2. **"知乎是万能平台"** — 实测推翻。技术性新话题，AI 引擎优先引用原创文章和科技媒体，而不是问答平台。

3. **"做了 SEO 就等于做了 GEO"** — SEO 是被索引的前提，但被索引不等于被引用。还需要段落化优化、结构化数据、权威建设。

4. **"AI 搜索会引用所有百度收录的内容"** — 不会。AI 搜索有引用偏好，权威来源的引用率远高于普通自建站。

5. **"等收录就好了"** — 收录只是第一步。内容太少时，即使被收录也几乎不会被引用。需要持续产出。
