## 关键实测结论（会话验证，权威性高于教科书）

### 术语
- 中国行业术语是 **GEO（生成式引擎优化）**，**不是 AEO**。
  - 搜"答案引擎优化"：秘塔只能引用英文站（seobility.net 等），无中文内容
  - 搜"生成式引擎优化(GEO)"：引用全部为中文站（louishe.com、ithome、tech.china 等）
- **写内容、做 SEO 都用 GEO 这个词。**

### 平台偏好（推翻"知乎是超级节点"假设）
- 测秘塔/豆包/千问搜"GEO"：**均未引用知乎**（0 个）
- 被引用的是：个人博客（louishe.com）、科技媒体（ithome/tech.china/ifeng）、开发者平台（aliyun）、学术（zenodo）
- 结论：技术性新话题优先引用**原创文章**（自建站/科技媒体），非问答平台
- **但知乎是实体锚点**：建立"纪优=GEO 研究者"身份，辅助 AI 判断可信度

### 建站/百度提交实战结论（2026-08-23 验证）
- GitHub Pages HTTPS 证书签发需 24-48h，配好 DNS 后等待即可，不是配置错误
- www 子域名配置 CNAME 前必须先删掉已有的 A 记录，否则阿里云报"解析记录有冲突"
- 百度资源平台：DNS 指向 GitHub 合法但百度不认 → **必须提交资源平台验证**
- 新站 sitemap 提交配额为 0 条 → 改用"普通收录-手动提交 URL"，每天少量提交
- 百度收录预计 1-4 周，用 `site:jiyou.site` 判断是否收录
