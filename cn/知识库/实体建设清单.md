# 中国实体建设清单（知乎篇）

> 第 7 周课程配套。目标：让 AI 认识"纪优"是一个 GEO 专家。
> 更新日期：2026-08-23

## 原理：为什么实体建设是 GEO 的一部分

**AI 回答你是谁，不是看你的网站，而是看跨平台的"身份块"是否一致。**

当 AI 引擎（秘塔/Kimi/百度AI搜）评估"纪优"是否可信时，它会搜集所有平台的零散信息合成一个判断：

```
知乎主页 + 自建站(jiyou.site) + 文章署名 + 评论发言
      ↘        ↙
  "纪优"实体 = AI 认定的权威度
```

**实测结论回顾：** 知乎不是技术话题的引用超级节点（搜 GEO 时 0 引用），但**知乎是实体锚点**——你的网站 JSON-LD 已经用 `sameAs` 指向知乎，这一步就是让两边对得上。实体建设 ≠ 引流量，而是**让 AI 拼图时拼出同一个"纪优"**。

## 一致性三原则（NAP 三件套的中文版）

1. **名字一致**：全平台统一用"纪优"
2. **简介一致**：所有平台简介都包含关键词"生成式引擎优化（GEO）研究"
3. **链接互通**：自建站 ↔ 知乎互相可见（网站 JSON-LD sameAs 知乎；知乎主页挂网站链接）

## 知乎主页检查清单

- [ ] 头像：专业人像或品牌化 logo（非风景/随意图）
- [ ] 一句话简介：含"生成式引擎优化（GEO）"
- [ ] 行业/职业资料：填写人工智能/营销咨询相关
- [ ] 个人主页链接：挂上 jiyou.site（如果知乎允许）
- [ ] 置顶一条原创内容（来自你的 GEO 文章改写）

## 文章分发改写规则（自建站 → 知乎）

| 维度 | 网站版（GEO 规格） | 知乎版 |
|------|------------------|--------|
| 首段 | 定义 + 自足段落实 | 先给结论 + 个人经验引入 |
| 每个 H2 问句 | 完整问句（供 AI 引用） | 小标题（人读为主） |
| 语气 | 客观、权威 | 有个人实践色彩 |
| 结尾 | 无 | 引导关注/收藏/评论互动 |
| 链接 | 少 | 可放网站原文"详细步骤见我的博客" |

**注意：** 不要把网站 HTML 原文直接复制到知乎（重复内容对两边都不好）。改写至少 30% 以上，加个人经验、删掉绝对化措辞。
